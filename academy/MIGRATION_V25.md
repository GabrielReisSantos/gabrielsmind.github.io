# Upgrading to v2.5 from CyberLab v2.4

## Recommended: use the complete project

1. Back up your working v2.4 project and export your CyberLab progress from **My Progress**.
2. Extract `cyberlab-interactive-v2.5-ad-mission-control.zip` into a new folder.
3. Run `npm install && npm run verify:ad-mission && npm test && npm run build`.
4. Run `npx playwright install chromium && npm run test:browser`.
5. Start with `npm run dev`; open `/training/#guide`, then `/training/#adlab`.

## Small patch

Apply `cyberlab-v2.5-patch-from-v2.4.zip` **only to the v2.4 source**, preserving your original directory as a backup. The patch includes changed source, new validation/unit/browser tests and release scripts. Don't apply it to older versions.

## Compatibility

Existing v2.4 learning progress, completed AD mission identifiers, certificate exercises, and cross-module enterprise configuration remain in the same browser storage keys. Draft recovery is a new additional storage key; it does not migrate fake or missing evidence from earlier releases.

## Before deploying

The actual Vite build and Playwright checks were not executed in the packaging environment because npm dependencies could not be downloaded. These are required local gates. For reproducible CI, commit the `package-lock.json` generated by `npm install` and run `npm ci` in GitHub Actions.
